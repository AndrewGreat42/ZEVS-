# Frontend: страницы и элементы интерфейса

| Маршрут | Страница | Права |
| --- | --- | --- |
| `/login` | Вход сотрудника | Публичный |
| `/` | Сводка | Авторизованные |
| `/rooms` | Список номеров и доступность | Авторизованные |
| `/rooms/new` | Добавление номера | ADMIN |
| `/guests` | Список гостей и поиск | Авторизованные |
| `/guests/new` | Добавить гостя | Авторизованные |
| `/bookings` | Список и фильтры бронирований | Авторизованные |
| `/bookings/new` | Новая бронь | Авторизованные |
| `/bookings/:id` | Карточка брони и статусные действия | Авторизованные |

## Будущие компоненты

`AppLayout`, `Sidebar`, `AuthForm`, `RoomTable`, `RoomForm`, `GuestTable`, `GuestForm`, `BookingTable`, `BookingForm`, `BookingStatusBadge`, `AvailabilityFilter`, `ConfirmDialog`, `LoadingSpinner`, `ErrorAlert`.

Каждая страница должна иметь состояния `loading`, `empty`, `success`, `error`. На конфликтный ответ HTTP 409 интерфейс показывает сообщение о занятости номера, не сохраняет бронь и предлагает изменить даты или номер. Ограничения прав проверяются **на сервере**, скрытие кнопок на frontend недостаточно.
