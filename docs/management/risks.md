# Риски проекта

| ID | Риск | Вероятность / влияние | Мера реагирования |
| --- | --- | --- | --- |
| R-01 | Не успеем реализовать весь MVP | Средняя / высокое | Сначала справочники и бронирования; не включать онлайн-оплату |
| R-02 | Двойная бронь при параллельных запросах | Средняя / высокое | `EXCLUDE` на стороне БД, интеграционные тесты |
| R-03 | Разночтения в требованиях | Средняя / среднее | Утверждать FR/BR и изменения с преподавателем |
| R-04 | Несоответствие API и frontend | Средняя / среднее | Единый `../design/api.md`, совместные проверки |
| R-05 | Git-конфликты и потерянные правки | Средняя / среднее | Ветки, PR и code review |
| R-06 | Сбой локального окружения | Средняя / среднее | Docker Compose, README, проверка версий |
| R-07 | Утечка тестовых паролей или данных гостей | Средняя / высокое | `.gitignore`, только синтетические данные |
| R-08 | Участник недоступен | Средняя / среднее | Документировать решения и проводить взаимное ревью |

Риски пересматриваются на еженедельной командной встрече.
