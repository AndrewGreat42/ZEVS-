## Контрольные точки

- **M1:** тема и требования согласованы с заказчиком.
- **M2:** на компьютере разработчика запускаются React, Spring Boot и PostgreSQL.
- **M3:** конфликт двойного бронирования отклоняется.
- **M4:** работает сценарий «создать гостя → бронь → подтвердить → заселить → выселить».
- **M5:** тесты и финальная демонстрация пройдены.

## Критерии готовности задачи (Definition of Done)

Критерии Issue соблюдены; код собирается; для нового поведения выполнены проверки; документация при необходимости обновлена; PR просмотрен другим участником; реальные затраты времени внесены в журнал.
